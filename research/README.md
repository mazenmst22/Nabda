# `research/`

Source material the product was built from, kept in its original form.

This is an archive, not a workspace. Files here are **read, never edited** — if a specification is superseded, add the new version alongside it rather than editing history out of the old one. Engineering interpretations of this material live in [`../docs/`](../docs/README.md).

## Layout

| Folder             | Contents                                                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `product-briefs/`  | Briefs that defined what to build. Currently the frontend build brief that fixes the stack, the patient-aggregate model, and the Vezeeta market reference. |
| `specifications/`  | Delivered specification documents — the Pulse MVP developer specification and the UX/UI specification and research manual.                                 |
| `source-archives/` | Packaged source drops received as archives, kept sealed for provenance.                                                                                    |

## Index

- [`product-briefs/nabda-frontend-build-brief.md`](product-briefs/nabda-frontend-build-brief.md) — stack, product model, routing and non-negotiables for the frontend.
- `specifications/nabda-cms-pulse-mvp-developer-specification.docx` — clinic management system and Pulse MVP, developer-facing.
- `specifications/nabda-uxui-design-specification-and-research-manual.docx` — UX/UI specification and research manual, brand-refresh revision.
- `source-archives/nabda-codex-pack.zip` — original Codex pack drop.

## Conventions

- Filenames are lowercase and hyphenated; the original title is preserved in this index, not in the filename.
- New revisions get a dated suffix (`-2026-09`), never an overwrite.
- Anything visual — prototypes, boards, tokens — belongs in [`../ux-ui/`](../ux-ui/README.md) instead.
